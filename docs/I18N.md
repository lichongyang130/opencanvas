# 多语言 i18n（中/英）

轻量自研方案：无路由段、无额外依赖，cookie 持久化。

## 使用

```ts
// 客户端组件
import { useI18n } from "@/lib/i18n";
const { t, locale, setLocale } = useI18n();
t("nav.chat");                       // 按当前语言取词
t("badge.unread", { n: 3 });         // 插值 {n}

// 服务端组件 / metadata
import { getLocale, getDict } from "@/lib/i18n/server";
```

- 字典：`src/lib/i18n/dicts.ts`（`en` 由 `Dict` 类型约束，新增 key 未翻译会编译报错）
- 法务长文：`src/lib/i18n/legal.ts`（隐私/条款结构化中英）
- 切换：`LanguageSwitcher` 组件或 Sidebar 底部「中/EN」按钮；写入 cookie `oc_lang` + localStorage
- SSR：`layout` 以 `generateMetadata` 按请求 cookie 输出 `<html lang>` 与 `title`；隐私/条款页服务端直出双语

## 已覆盖范围

首页核心区、登录/注册、账号菜单、侧栏图标提示、积分/通知徽章、设置中心标题与分页、
业务页 H1、隐私/条款整页。

## 未覆盖（渐进）

- API 返回的服务端错误信息（保持中文，后续可为常见错误加 `errorCode` + 前端映射）
- 设置中心内部各卡长文案、业务数据（模板内容、智能体系统提示词等，属于用户内容，不翻译）
