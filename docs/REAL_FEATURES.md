## 二、六个占位页面 → 应实现的实际功能

### 1. 智能体 agents（11 个占位按钮）
| 占位 | 实际功能 |
|---|---|
| 创建智能体 | 智能体 CRUD：名称/头像/系统提示词/模型/温度；存 SQLite `agents` 表；与对话绑定（复用现有 persona 概念） |
| 查看全部 | 智能体列表（我的/官方/收藏），从 mock 数据改为真实表 |
| 更多操作 | 编辑 / 复制 / 删除 / 设为默认智能体 |
| 分享智能体 | 生成分享码（复用 cases/share 机制），/s/[code] 渲染智能体卡片 + 「用这个智能体对话」 |

### 2. 文档中心 docs（9 个占位按钮）
| 占位 | 实际功能 |
|---|---|
| 上传文档 | 文件上传接口（PDF/DOCX/MD/TXT）+ 解析 + 入库 `documents` 表；PDF 用 pdf-parse，DOCX 用 mammoth |
| 打开文档 | 文档详情页/抽屉 → 复用 DocView 编辑 + AI 操作 + 导出 Word |
| 新建文件夹 | folders 表 + 树形导航 |
| 批量操作 | 多选 → 移动/删除/导出 |
| 分享文档 | 生成分享码 → 只读页 |
| 筛选 | 类型/标签/时间/排序 + 搜索（标题/内容全文） |
| 管理存储空间 | 文件大小统计、配额展示、清理 |
| 查看全部 | 分页列表 |

### 3. 知识库 knowledge（8 个占位按钮）
| 占位 | 实际功能 |
|---|---|
| 上传文档/建知识库 | 文件 → 解析 → 分块 → Embedding（bge-m3 / openai embedding）→ 向量库；提供「知识库 API Key」配置（设置中心新增分组） |
| 打开文档 | 库内文档预览、切片查看、删除 |
| 筛选 / 查看全部 | 库列表真实数据 + 搜索 |
| 分享知识库 | 分享码 → 只读页 |
| 管理知识库 | 重命名/删除/容量统计 |
| **对话引用**（核心价值）| /api/chat 或写文档时注入检索片段（RAG：query → 向量检索 top-k → 拼入上下文） |

### 4. 模板中心 templates（6 个占位按钮）
| 占位 | 实际功能 |
|---|---|
| 提交模板 | 表单 → `prompt_templates` 表（标题/分类/变量/提示词/作者）；「共享模板库」区显示真实数据 |
| 场景筛选 | 分类筛选接真实数据 |
| 换一批 | 随机/推荐排序接口 |
| 查看全部 | 分页 + 搜索 |
| 模板预览 | 已有 PreviewThumb 静态图 → 改为真实提示词预览与「一键运行」（复用 fillTemplate/runTemplate）|

### 5. 工具箱 tools（≥8 个工具全是占位）
| 占位 | 实际功能（每个都应有真实动作，按价值排序） |
|---|---|

| 语音转文字 | 接 Whisper/豆包 ASR API |
| 图片压缩/抠图 | 本地 canvas/后端 sharp + remove.bg 类 API |
| PDF 工具 | 合并/拆分/转 Word（pdf-lib + mammoth） |

### 6. 更多应用 apps（2 个占位按钮）
| 占位 | 实际功能 |

## 三、通用基础建设（跨页面复用）

1. **文件上传与解析**（最高优先，docs/knowledge/tools 都依赖）
   - `POST /api/files`：multipart → 磁盘/内存存储 → PDF/DOCX/MD/TXT/图片解析出纯文本
   - 前端 `<input type=file>` 拖拽上传组件（工作台输入框附件 UI 已有占位）
2. **数据库 schema 扩展**：SQLite 增加 `agents` / `documents` / `knowledge_bases` / `kb_chunks` / `prompt_templates` / `apps` / `notifications` 表（prisma schema 已备）
3. **向量检索（RAG）**：Embedding 模型可选（OpenAI/通义文本向量/本地 bge），表存 chunk + vector（JSON）
4. **通知中心**：顶栏铃铛目前无功能 → 任务完成/错误/分享提醒（SSE 或轮询）
5. **用户与积分**：目前单用户本地版；上线前需登录（Clerk/手机号）、积分扣减落库（见 roadmap 10/11）
6. **深色模式**：设置页已留占位，全局 CSS 变量主题化（工作量中等）
7. **移动端适配**：右侧画布改底部抽屉（改进建议第 60 条）

## 四、建议实施顺序（P0 → P2，按依赖与演示价值）

**P0（打通全部现有能力，2~3 步内见效）**
1. 文件上传/解析基础设施 → 文档中心真实可用（上传/打开/搜索）
2. 模板中心接真实数据 + 一键运行（引擎全都有，只差入口）
3. 智能体 CRUD + 分享（复用 persona 与 share API）

**P1（产品差异化）**
4. 知识库 RAG：上传 → 向量化 → 对话引用（招牌功能）
5. 工具箱真实工具（文案/周报/摘要/翻译直接复用对话引擎）
6. 通知中心 + 铃铛联通

**P2（商业化/扩展）**
7. 代码生成沙箱预览、视频生成（可灵/Seedance）、素材包补齐
