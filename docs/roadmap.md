# OpenCanvas AI 功能路线图 / Backlog

> 当前已有：多模型网关（国内外 + 前台 BYOK）、流式对话、PPT 生成/编辑/导出 PPTX、
> AI 绘图、数据持久化（SQLite）、历史管理（搜索/筛选/置顶/重命名/归档/批量）、场景模板、落地页。
> 下面按优先级列出可继续增加的内容。优先级：P0 必做 / P1 高价值 / P2 中长期。

## 一、核心创作能力（补齐对标 HIX/Genspark）

### 1. 深度研究 Deep Research（P0，最该做）
- 联网搜索：接 Tavily / Exa（海外）、博查/秘塔（国内）
- Agent 多轮检索：拆问题 → 并⾏搜索 → Jina Reader 读网页 → 去重打分 → 补搜
- 输出**带引用角标**的研究报告（Artifact 文档）
- 报告**一键转 PPT**（打通研究→演示招牌链路）
- 异步任务 + WebSocket/SSE 进度（"正在阅读第 N 个来源"）
- 预估工作量：中（复用现有网关 + 队列思路）

### 2. 富文本文档编辑器（P0）
- ✅ 画布内编辑（Markdown 编辑/分屏/预览）、AI 操作（续写/改写/扩写/缩写/纠错）、导出 Word/PDF/Markdown、独立文档库（/docs）
- ✅ TipTap 所见即所得富文本（标题/粗斜体/列表/引用/代码块/撤销重做；Markdown 双向转换，下游 AI/导出链路不变）

### 3. AI 视频生成（P1）
- 文生视频/图生视频：接 Seedance、Kling、可灵（国内）、Veo（海外）
- 分镜脚本 → 逐镜生成 → 合并 → 视频画廊（复用图像工作台 UI）
- 异步任务队列（分钟级），进度推送
- 配音/字幕（TTS）

### 4. Agent「一句话出整套素材包」（P1，HIX 主打）
- 多节点工作流编排（LangGraph 风格）：
  新品发布 = 研究 → 文案×N → 配图×N → 视频脚本 → PPT
- 节点产物共享上下文（品牌语调 + 研究结论）
- 预置包：产品发布套件、社媒 campaign、网络研讨会、儿童绘本、电商详情页

### 5. 代码生成与预览（P1）
- 生成 HTML/React 单页，iframe 沙箱实时预览
- 落地页/原型/小工具一键生成，截图/部署

### 6. PPT 能力增强（P1）
- ✅ 「配图位」自动调绘图模型填真实图片：单页/批量「AI 配图」，有 Key 用 DALL·E 3 / 万相，否则演示 SVG，imageUrl 随会话持久化
- ✅ 更多版式：时间轴（timeline）/ 对比（compare）/ 流程（process）/ 引言（quote）/ 团队（team），模型 prompt 与解析器同步支持
- ✅ 导出 PDF（浏览器打印逐页输出，@media print 横版）
- ✅ AI 单页重写（真实模型改写选中页，版式可智能适配，旧配图作废可重新生成）
- ✅ 演讲者备注编辑、主题市场、大纲先行

### 7. 图像能力增强（P2）
- ✅ 接入 FLUX：fal.ai FLUX.1 Schnell（文生图）/ Dev（图生图），设置页可配 FAL_KEY、测试连接并拉取模型列表；/api/images 支持 model 指定与 imageUrl 图生图
- ✅ 接入 Seedream 同源通义万相：wan2.7-t2i-flash / wanx2.5-t2i（文生图）、wan2.5-i2i-preview（新版图生图，兼容旧 wanx2.1-i2i-turbo）
- ✅ 图生图：图片工作台「参考图（图生图）」按钮（上传图片附件即作为参考图），画布每张图可一键生成变体（自动选 FLUX dev / 万相 2.5 i2i）
- ✅ 背景移除：每张图「去背景」按钮，优先服务端 remove.bg（REMOVE_BG_API_KEY），未配置时客户端 @imgly WASM 本地 AI（免费、模型 CDN 加载）
- ✅ 绘图模型选择器：图片模式参数行可选「自动 / FLUX / 万相 / DALL·E」，生成成功按模型扣积分
- ⬜ 局部重绘、扩图、Logo/海报/社媒尺寸模板、组图（多视角/多场景）、可灵图像

### 8. 品牌中心 Brand Kit（P2）
- 上传 Logo、色板、字体、品牌语调描述
- 所有 PPT/图/文案自动套用，保持风格一致

### 9. 知识库 RAG（P2）
- ✅ 知识库接入工作台对话：会话可绑定知识库（KbPicker），发送消息自动检索命中片段并注入 system 上下文，回答下方展示引用来源卡片（文档名 + 片段 + 相关度）并可折叠
- ✅ 语义向量化：零依赖 TF-IDF + cosine 语义检索，与关键词命中融合排序（接口不变，可替换 Embedding）
- ✅ 上传网页自动入库、Embedding 向量库（当前复用文档中心：PDF/Word/TXT/MD 上传解析后关联入库）

## 二、账户与商业化

### 10. 用户体系（P0 商业化前置）
- ✅ 本地账号版：邮箱+密码注册/登录/登出（scrypt 哈希 + httpOnly cookie 会话，零外部依赖），首页/工作台顶栏 + 首页左侧用户卡片（真实登录态，Portal 弹窗不被遮挡）
- ✅ 会话按用户归属（conversations.userId）：未登录=本地，登录后新会话归本人，列表按身份过滤
- ✅ Google / GitHub OAuth 登录（本地版内置，标准授权码流程 + state 防 CSRF；需在 Google Cloud / GitHub 创建 OAuth 应用并配置 .env 凭据，回调地址见 .env.example）
- ⬜ 海外托管版：Clerk/Auth0（多租户、社交登录聚合）
- ⬜ 国内：手机号验证码 + 微信登录
- ✅ 全表隔离（文档/知识库/积分/通知，账号导出与删除同步覆盖）
- ✅ PostgreSQL 版用户体系（完整 Prisma schema + 迁移/导入/冒烟脚本，PG 18.4 实测通过）

### 11. 积分与支付（P1）
- 积分账本真实落库（现在是纯函数）：预扣、结算、流水
- 订阅套餐 + 充值包
- 海外 Stripe；国内微信支付/支付宝（聚合）
- 用量/账单页面

### 12. 团队与协作（P2）
- 团队工作区、成员、共享品牌库/模板
- 产物链接分享（只读页）、评论

### 13. API 开放平台（P2）
- 对外 OpenAI 兼容接口，按 token 计费
- 开发者文档、API Key 管理
