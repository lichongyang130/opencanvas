# OpenCanvas 演示脚本（5 分钟版）

> 面向用户/评审的端到端走查。每个环节都调用真实功能，全程无「演示预览/即将接入」。
> 前置：`npm run dev` 已启动，浏览器打开首页。

## 0. 开场（30s）
- 展示首页顶栏：🔔 通知（真实未读角标）、🪙 积分徽章（今日任务）、🖥 开启右侧预览、⚙️ 设置
- 一句话：**「这个工作空间里 7 个页面现在都是真实数据驱动的，我们从文件开始。」**

## 1. 文档中心（60s）
1. 顶栏切到「文档/Apps」→ 文档中心
2. 拖入 `报告.md`（或 PDF/DOCX）→ 提示「已上传 1 个文档」
3. 自动出现通知 + 积分 +5（点击铃铛可跳回）
4. 搜索框输入正文关键词（中文，如「知识库」）→ 命中该文档
5. 打开正文预览抽屉 → 收藏 → 回收站/下载 各演示一次

## 2. 模板中心（45s）
1. 切到「模板中心」
2. Tab「热门/最新/我的提交」；热门 Top3 有 🔥 徽章（uses 真实）
3. 「提交模板」：名称 + 含 `{{产品}}` 的提示词 → 变量实时预览 → 提交
4. 新模板出现在「我的提交」，hover 删除可用
5. 点内置模板 → 变量填值 → 一键运行 → 跳 `/chat` 并真实发送，共享模板 uses +1

## 3. 智能体（45s）
1. 切到「智能体」
2. 官方智能体（13 个真实角色，展示系统提示词在右侧详情）
3. 「创建智能体」→ 点「从官方角色开始」选「爆款文案专家」→ 改名为自己的 → 保存
4. 列表出现自己智能体；「分享智能体」→ 复制 `/s/xxx` 链接 → 新标签打开分享页 → 「立即使用」直达对话
5. `✕` 删除演示（二次确认）

## 4. 知识库 RAG（60s）
1. 切到「知识库」→ 新建「产品文档库」
2. 「管理文档」→ 把文档中心的报告添加进去（真实关联，统计 +1）
3. 「提问」→ 输入「知识库怎么实现？回答时能引用来源吗」→ 命中片段（关键词高亮、相关度得分）
4. 「让 AI 基于片段回答」→ 流式答案 + 引用标注
5. 能力设置：关闭语义检索 → 再提问，降级为最近文档片段（如实说明降级行为）

## 5. 工具箱 + 通知（30s）
1. 切到「工具箱」→ 搜索「翻译」→ 工具实时过滤
2. 点「中英翻译」→ 自动进 `/chat` 且指令已预填（粘贴内容发送即真实执行）
3. 回到任意页面点 🔔 → 通知列表按时间排序、全部已读

## 6. 代码沙箱（45s）
1. `/chat` 输入：「写一个番茄钟倒计时页面，HTML 格式」
2. 回复完成后 hover 消息 → 「⚡ 运行预览」
3. 右侧沙箱：iframe 内倒计时可交互；「重新运行」「复制源码」「新窗口打开」
4. 刷新页面 → 预览仍在（codePreview 持久化）

## 7. 深色模式 + 积分（45s）
1. ⚙️ 设置 → 通用 → 外观主题 → 深色 → 整站即时变暗（品牌色自动提亮）
2. 逛一遍 5 个页面验证卡片/边框/文字对比度；系统主题模式可跟随
3. 积分徽章 → 今日任务 →「签到」→ +10 且徽章弹跳；流水可见
4. 切回浅色收尾

## 8. 收尾词（15s）
「P0/P1 全部接真，P2 的代码沙箱、积分、深色模式也已上线；文生视频、OCR、团队协作需要外部服务，界面已诚实标注『规划中』，不再假装可用。」
